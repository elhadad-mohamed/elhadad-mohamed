### About me

I'm a Mechatronics & Industrial Automation Engineering graduate from **Galala University**. I like working across the whole stack of a machine: the mechanical design, the control logic, and the embedded code that ties them together.

- ⚙️ **Industrial automation:** PLC programming (ladder logic, I/O mapping, timers/counters, interlocks), classic control circuits, VFDs and motor drives
- 🔌 **Embedded systems & robotics:** Embedded C on AVR/ATmega32, Arduino, sensor fusion, MATLAB/Simulink
- 📐 **Mechanical design & simulation:** SolidWorks, CATIA, AutoCAD, Abaqus FEA, CNC machining
- 🥽 **VR for engineering training:** my graduation project is a VR workshop simulator built in Unreal Engine 5 (graded *Excellent*)
- 🎯 **Looking for:** entry-level roles in industrial automation, robotics, manufacturing or design & production engineering
